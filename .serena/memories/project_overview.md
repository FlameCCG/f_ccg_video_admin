# admin-console 项目概览
- 项目是一个 Vue 3 + TypeScript 企业级后台管理系统，面向视频网站 Admin Console。
- 技术栈：Vue 3、TypeScript(strict)、Vite、Vue Router、Pinia、@tanstack/vue-query、Axios、vue-i18n、Naive UI、Tailwind CSS、Sass。
- 质量工具：ESLint、Prettier、Stylelint、Vitest、vue-tsc、Husky、commitlint。
- 代码目录：`src/api` 接口与类型，`src/views` 页面，`src/components` 通用组件，`src/composables` 组合式逻辑，`src/stores` Pinia，`src/router` 路由，`src/locales` 多语言，`src/styles` 主题与样式。
- 文档目录为 `doc/`，包含用户、视频、站点、RBAC 等后端 API 契约文档。
- 当前系统为 Windows / PowerShell 环境。
